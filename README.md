# Анализ рынка недвижимости Ames: от данных до бизнес-рекомендаций.
## 📌 О проекте

**Датасет:** House Prices - Advanced Regression Techniques — 79 характеристик объектов жилой недвижимости, задача регрессии для прогнозирования стоимости продажи.

**Цель:** дать рекомендации стейкхолдерам рынка (покупателям, инвесторам, риелторам и оценщикам).

**Стек:** Python (Pandas, Scikit-learn, NumPy, Matplotlib, Seaborn, SHAP), Яндекс DataLens, Google Colab

## 🔁 Пайплайн проекта

1. **Подготовка и разведочный анализ (EDA)** — в Google Colab:
   описание датасета, ETL-пайплайн (очистка, заполнение пропусков,
   кодирование категориальных признаков, нормализация), анализ
   распределений и корреляций.

2. **BI-дашборд** — в Яндекс DataLens:
   обзор рынка → стратификация по районам → влияние качества на цену →
   выводы и рекомендации для стейкхолдеров.

3. **Моделирование стоимости** — Scikit-learn:
   обучение нескольких моделей, их сравнение и анализ ошибок прогноза.

4. **Интерпретация модели** — SHAP:
   объяснение вклада отдельных признаков в итоговую стоимость жилья.
