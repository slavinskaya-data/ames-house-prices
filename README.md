# Анализ рынка недвижимости Ames: 
# от данных до бизнес-рекомендаций.
Датасет House Prices - Advanced Regression Techniques содержит 79 характеристик объектов жилой недвижимости и предназначен для решения задачи регрессии с целью прогнозирования их итоговой стоимости продажи.

Цель проекта – дать рекомендации стейкхолдерам рынка (покупателям недвижимости, инвесторам и риелторам/оценщикам).

Стек технологий: Python(Pandas, Scikit-learn, NumPy, Matplotlib, Seaborn, SHAP), Яндекс DataLens

Ключевые выводы проекта:
1) Распределение цен имеет правостороннюю асимметрию, из-за чего медиана является более точной мерой центральной тенденции, чем среднее арифметическое
2) Ключевые драйверы ценообразования - общее качество отделки и жилая площадь
3) Локация задает базовый уровень цены, формируя устойчивую стратификацию рынка.
